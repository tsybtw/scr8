# scr8

[English](README.md) | [Українська](README.uk.md) | **Русский**

Мгновенные скриншоты выбранной области экрана по горячей клавише. Для
Windows и macOS.

Вы один раз настраиваете **бинд**: область экрана, папку и комбинацию
клавиш. Потом в любой программе нажимаете комбинацию, и скриншот этой
области сразу сохраняется в папку. Никаких окон и звуков. 10 нажатий за
секунду дают 10 скриншотов, а если зажать комбинацию, получится один.

## Скачать

| Система | Файл |
| --- | --- |
| Windows 10 и 11 | [**scr8-windows.exe**](https://github.com/tsybtw/scr8/releases/latest/download/scr8-windows.exe) |
| macOS 11 и новее (Intel и Apple M1 и новее) | [**scr8-macos.dmg**](https://github.com/tsybtw/scr8/releases/latest/download/scr8-macos.dmg) |

## Установка на Windows

1. Скачайте `scr8-windows.exe` и положите его в любую удобную папку.
   Устанавливать ничего не нужно, это вся программа.
   Если браузер предупредит, что файл скачивают редко, выберите
   **Сохранить**.
2. Запустите файл. При первом запуске Windows может показать окно
   «Система Windows защитила ваш компьютер». Нажмите **Подробнее** →
   **Выполнить в любом случае**. Так бывает с программами, у которых нет
   платной цифровой подписи.

Если позже переместите файл в другую папку, просто запустите его заново
из нового места.

## Установка на macOS

1. Откройте `scr8-macos.dmg` и перетащите **scr8** в папку **Программы**.
2. Запустите scr8 из папки «Программы». Первый запуск macOS заблокирует,
   потому что программа не из App Store:
   - **macOS 14 и старше:** нажмите на scr8 правой кнопкой → **Открыть** →
     **Открыть**.
   - **macOS 15 и новее:** закройте предупреждение, откройте **Системные
     настройки → Конфиденциальность и безопасность**, пролистайте вниз,
     нажмите **Всё равно открыть** рядом с сообщением про scr8 и подтвердите
     паролем.

   Это нужно сделать только один раз.
3. Разрешите запись экрана. macOS сама попросит это при первом запуске.
   Включите **scr8** в **Системные настройки → Конфиденциальность и
   безопасность → Запись экрана** и перезапустите scr8 (macOS предложит это
   сделать). Без этого разрешения macOS не даёт делать скриншоты ни одной
   программе.

На Mac у scr8 нет значка в Dock. Программа живёт в **строке меню** вверху
экрана: это значок из четырёх уголков рамки.

<details>
<summary>macOS пишет, что scr8 «повреждён» и его нельзя открыть</summary>

Откройте программу **Терминал**, вставьте эту команду, нажмите Enter и
снова запустите scr8:

```
xattr -dr com.apple.quarantine /Applications/scr8.app
```

</details>

## Как пользоваться

При первом запуске окно scr8 откроется само. Потом его можно открыть
значком scr8: на Windows он в трее справа внизу (может прятаться под
стрелкой **^**), на Mac — в строке меню (пункт **Open scr8**).

**Создать бинд:**

1. Нажмите **New bind**. Экран «замрёт».
2. Выделите мышью нужную область. Её можно двигать, потянув за середину,
   и менять размер, потянув за край или уголок. Нажмите **Enter** (или
   дважды щёлкните по области), чтобы сохранить. **Esc** отменяет.
3. Выберите папку, куда сохранять скриншоты.
4. Нажмите комбинацию клавиш, например **Ctrl + Alt + 1** (на Mac,
   например, **Cmd + Shift + 1**). Нужна хотя бы одна клавиша-модификатор
   (Ctrl, Alt, Shift, Win, на Mac Cmd и Option); клавиши F1–F20 можно и
   без неё. **Esc** отменяет.

Готово: справа у бинда появится зелёная надпись **active**. Теперь нажатие
комбинации сохраняет скриншот в выбранную папку.

**Кнопки у бинда:**

| Кнопка | Что делает |
| --- | --- |
| **Change** | Задать другую комбинацию клавиш |
| **Edit area** | Изменить область |
| **➕ Edit hotkey** | Задать вторую комбинацию, которая открывает изменение области этого бинда из любой программы, не открывая окно (✖ удаляет её) |
| **Choose…** | Выбрать другую папку |
| **Open** | Открыть папку со скриншотами |
| Переключатель рядом с 🗑 | Выключить или включить бинд. Выключенный бинд сохраняет все настройки, но не делает скриншоты, а его комбинации свободны для других программ |
| 🗑 | Удалить бинд |

Название бинда (например, «Bind 1») можно поменять, нажав на него. С него
начинается имя файла скриншота.

## Полезно знать

- **Крестик окна не выключает программу**, она продолжает работать в
  фоне. Чтобы выйти, нажмите на значок scr8 → **Quit**.
- **scr8 запускается вместе с системой.** Выключить это можно на вкладке
  **Advanced** → **Start with system**.
- **Если запустить scr8 ещё раз**, откроется окно уже работающей программы.
- **Если скриншот не сохранился** (например, папку удалили или отключили
  флешку), значок scr8 станет красным, на Windows придёт уведомление, а
  внизу окна появится текст ошибки. Нажмите ✖, чтобы убрать сообщение.
- **Красная надпись у бинда** значит, что эта комбинация уже занята
  другим биндом или другой программой. Нажмите **Change** и выберите
  другую.
- **Качество.** Скриншоты всегда сохраняются в PNG без потери качества. На
  вкладке **Advanced** можно выбрать степень сжатия: **Fast** (по
  умолчанию) сохраняет быстрее всего с нормальным размером файла, **Best**
  даёт файлы чуть меньше, но медленнее. Кнопка **Run test** покажет, сколько
  времени и места занимает скриншот на вашем компьютере.

## Обновление

Скачайте новую версию по ссылкам выше.

- **Windows:** закройте scr8 (значок → **Quit**) и замените старый файл
  новым.
- **Mac:** закройте scr8 (значок → **Quit**) и перетащите новую версию в
  «Программы» с заменой. Если после обновления скриншоты перестали
  работать, откройте **Запись экрана** в настройках, удалите scr8 из списка
  кнопкой **−**, добавьте снова и перезапустите scr8.

## Удаление

1. На вкладке **Advanced** снимите галочку **Start with system**.
2. Закройте scr8: значок → **Quit**.
3. Удалите файл `scr8-windows.exe` (на Mac перетащите scr8 из «Программ» в
   Корзину).

Настройки хранятся в `%APPDATA%\scr8` на Windows и в
`~/Library/Application Support/scr8` на Mac; эти папки тоже можно удалить.
